# Provenance notes

The hand source states that its geometry was generated independently around the architecture of the e-NABLE Phoenix family, including Phoenix v2/v3 and Unlimbited Phoenix. This is a statement in the source, not an independent provenance audit.

Reference starting points: [e-NABLE](https://enablingthefuture.org/) and [Team Unlimbited](https://www.teamunlimbited.org/).

The maintainer should add exact design-page links, versions, relevant upstream licenses, and a clear list of original changes. Audit the supplied 3MF and STL exports as well as source. The directory name phoenix-hand-v8 is retained for compatibility; it should not be read as verified upstream versioning or endorsement.
