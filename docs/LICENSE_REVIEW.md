# Licensing checklist for the maintainer

The original LICENSE is preserved. Its heading names MIT and CC-BY-SA-4.0, its body contains custom permission and warranty language, and the original README instead named CERN-OHL-P-2.0 and CC-BY-SA-4.0. This documentation revision does not settle those inconsistencies.

Before release:

- Establish authorship and provenance for each source and exported asset.
- Determine which license applies to CAD, software, documentation, and media.
- State whether multiple licenses are alternatives or cover different files.
- Include the complete official text of each selected license.
- Preserve required upstream attribution and notices.
- Update the root README and file headers to match the final decision.

Do not describe this snapshot as unambiguously licensed under standard terms until these questions are resolved.
